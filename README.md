# Sign-language-Detection

Simple car color Detection model using machine learning

## To simply run this model:
1. Clone this repository
2. Run the [gui.py](https://github.com/Anshuydv55/Car-Color-Detection/blob/main/gui%20Car%20Detection.py) file
3. Upload the Image you want to detect
4. Click on detect button
5. View results

 ## To Run this Model yourself:
 
1. Clone this repository
2. Download the dataset from [here](https://www.kaggle.com/datasets/landrykezebou/vcor-vehicle-color-recognition-dataset).
3. Extract the dataset to your repository folder.
4. Open the [Model jupyter notebook](https://github.com/Anshuydv55/Car-Color-Detection/blob/main/car%20code%2011042025.ipynb)
5. Run this notebook
6. Run the [gui.py](https://github.com/Anshuydv55/Car-Color-Detection/blob/main/gui%20Car%20Detection.py) file
7. Upload the Image you want to detect
8. Click on detect button
9. View results
